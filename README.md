# sharedcue.github.io

The SharedCue website and blog, built with [Astro](https://astro.build) and published to
GitHub Pages at <https://sharedcue.github.io/>.

```sh
npm install
npm run dev      # http://localhost:4321/
npm run build    # production build into dist/
```

Every push to `main` deploys automatically via `.github/workflows/deploy.yml`.

How to write posts and edit pages: see [CONTENT.md](CONTENT.md).

The theme is based on the Astro blog starter, itself based on [Bear Blog](https://github.com/HermanMartinus/bearblog/).
